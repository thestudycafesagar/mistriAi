# Python dependencies for parse_bank_statement.py — the local bank-statement
# parser that src/lib/pythonBankParser.ts invokes as a subprocess before
# falling back to Mistral OCR. Tested against the versions below; >= is used
# instead of exact pins so this installs cleanly across Python versions.
#
# Tesseract-OCR and Poppler are separate system packages (not pip-installable)
# needed only for the scanned/image-PDF OCR fallback inside the script itself
# — native (text) PDFs work without either. If they're not installed, the
# script's OCR branch fails gracefully and src/lib/pythonBankParser.ts falls
# back to Mistral, same as any other local-parse failure.
#
# opencv-python-headless (NOT plain opencv-python): this script only ever
# calls cv2.cvtColor()/cv2.threshold() — no GUI/display functions — but plain
# opencv-python still links against GUI/OpenGL libraries (libGL.so.1) that a
# headless server has no reason to have installed, causing `import cv2` to
# fail with "ImportError: libGL.so.1: cannot open shared object file" even
# though the package itself installed successfully. Confirmed on a real VPS
# deployment (Debian, no X11/desktop packages). -headless is a drop-in
# replacement — same `cv2` module/API, built without the GUI dependency — so
# this is a pure packaging fix with no code change needed. Don't install both
# opencv-python and opencv-python-headless in the same environment; they
# conflict (both provide the `cv2` import).
opencv-python-headless>=4.9
numpy>=1.26
pdfplumber>=0.11
pandas>=2.2
pytesseract>=0.3.10
pdf2image>=1.17
openpyxl>=3.1
