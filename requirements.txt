# Python dependencies for parse_bank_statement.py — the local bank-statement
# parser that src/lib/pythonBankParser.ts invokes as a subprocess before
# falling back to Mistral OCR. Tested against the versions below; >= is used
# instead of exact pins so this installs cleanly across Python versions.
#
# This script handles NATIVE (text-based) PDFs only — pdfplumber reads real
# embedded text/table structure deterministically, for free. A scanned/
# image PDF (or any PDF pdfplumber can't pull real text from) is NOT OCR'd
# locally; the script fails fast and src/lib/pythonBankParser.ts falls
# through to Mistral OCR immediately, which already does real OCR as part
# of its normal extraction. An earlier version ran its own Tesseract-based
# OCR pass here first (opencv-python/pytesseract/pdf2image, plus the
# Tesseract-OCR and Poppler system packages neither is pip-installable
# without), but that added real deployment fragility across environments —
# missing system packages on a fresh VPS, a missing libGL.so.1 for the
# GUI-linked opencv-python build, missing Poppler on a local Windows dev
# box — and even when installed correctly, running full OCR across every
# page of a large scanned statement before ever trying Mistral could take
# several minutes, almost always wasted. Removed entirely in favor of
# failing fast to the fallback that was always going to run anyway.
pdfplumber>=0.11
pandas>=2.2
openpyxl>=3.1
